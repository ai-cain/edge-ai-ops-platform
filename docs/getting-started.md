# Getting Started

## What the current scaffold includes

- root repo structure
- backend and frontend folders
- Docker Compose workflow
- MkDocs-based project docs
- sample backend domain routes
- sample frontend operator pages

## Local commands

```bash
make dev
make backend-test
make frontend-build
make docs-serve
```

## Services

- frontend on `http://localhost:5173`
- backend on `http://localhost:8000`
- API docs on `http://localhost:8000/docs`
- docs on `http://localhost:8001` when serving MkDocs
- PostgreSQL on `localhost:5432`
