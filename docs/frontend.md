# Frontend

The frontend is the main product surface for this repository.

## UX goals

- high-signal overview dashboard
- fleet table with device drill-down
- AI event stream with filters
- inspections workspace
- clear loading, empty, error, and stale states

## Shape

- React application shell
- domain pages and routes
- reusable UI components
- typed API client
- TanStack Query for server state
- WebSocket hooks for live updates

## Current scaffold pages

- overview
- devices
- telemetry
- ai-events
- inspections
